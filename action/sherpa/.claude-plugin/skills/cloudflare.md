---

Manage cloudflare resources using the MCP server `cloudflare`.

Usage:
- Application code runs on workers.
- Static assets get uploaded to R2 buckets.
- Redis and Key Value stores go into KV Namespaces
- Databases are created with D1 Databases.

Always read resources and confirm plans with user before updates.
