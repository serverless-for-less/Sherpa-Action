# Contributing to Sherpa Action

Thank you for your interest in contributing to Sherpa Action! This guide covers our development practices and how to get involved.

## Development Workflow

1. Fork the repository
2. Create a feature branch from `main`
3. Make your changes
4. Submit a pull request
5. Address review feedback
6. Merge once approved

## Code of Conduct

Be respectful, inclusive, and constructive. We're building something together.
